# Unread clears on activate or mark read, not on opening the panel

The badge exists to nag. If opening the panel marked everything read, the first peek would zero the cue and the list would lose contrast. Activation (open the link) means the person dealt with that item. Explicit mark read (including mark-all on the current recent list) covers “seen, not opening.” History outside the recent window is not kept as a badge debt.
